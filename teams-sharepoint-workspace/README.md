# Teams-connected collaboration workspace

This local acceptance check records the intended mapping for the Northstar Teams workspace. It models the design; it does not call Microsoft Teams or SharePoint APIs.

Run it with:

```bash
python3 src/workspace_check.py
```

Expected output:

```text
Files -> Documents/General [Northstar members]
Guidance -> Guidance library [Northstar members]
Onboarding -> HR Onboarding list [Northstar members]
Jordan: denied
```
