# Viva Connections employee experience

This local contract records the Northstar content selected for a Viva Connections feed and the portal destination used by Resources.

Run it with:

```bash
python3 src/main.py
```

The script validates the intended feed sources and Resources link. It does not configure SharePoint or Teams remotely. Verify SharePoint publication, audience access, Viva Connections settings, and Teams app setup policies in the tenant separately.
