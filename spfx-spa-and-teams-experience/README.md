# SharePoint and Teams web-part experience

This prototype models one Northstar Status experience rendered for a SharePoint full-page app part and a Teams tab.

Run it with:

```text
python3 src/main.py
```

The output keeps the same status records while selecting a wide SharePoint layout and a compact Teams layout. In a deployed SPFx solution, advertise the corresponding hosts in the web-part manifest and verify the published page and Teams surface with representative viewer permissions.
