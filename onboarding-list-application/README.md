# Onboarding list application

A small runnable model for the onboarding list lesson.

## Run

```bash
python3 src/main.py
```

Expected output:

```text
Jordan Lee: ['Maya Chen', 'Luis Ortega']
Needs review: ['Luis Ortega', 'Priya Shah']
```

The model represents the SharePoint list contract locally. Configure the corresponding SharePoint list with fields for Employee name, Start date, Owner, Status, and Next review, then create views for intake, ownership, and review.
